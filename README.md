# Markwright

This application is a Markdown editor with three views: **Raw**, where you type the Markdown syntax yourself; **Formatted**, which you edit directly (with a formatting toolbar, keyboard shortcuts, editable tables, task checkboxes and inline images); and **Dual**, which shows both side by side, scrolling together. Switching views keeps your place, your last-used view is remembered, documents auto-save as you type, every document is a tab so several can be open at once, a version history (File > Revert To) lets you step back past auto-saves, and the app reopens whatever you were working on (including unsaved untitled drafts). It also has a library sidebar (a folder of sheets and groups with search, keyword filters and Quick Open), a dashboard (statistics, reading time, writing goals with deadlines, outline navigator, keywords, attachments), typewriter scrolling, focus mode, composition mode, editor themes and fonts, comments and metadata blocks, find and replace, grammar checking, splitting a sheet at the cursor, and export to HTML, PDF, Word and RTF with a styled preview and printing. It also supports `[[wiki links]]` between sheets with autocomplete, a Backlinks panel and a Links list in the dashboard, inline `#tags` (nested as `#a/b`) that feed the library's tag tree and filters (click a tag in the dashboard to jump to it in the text, or right-click it to filter the library), `==highlight==`, footnotes (`[^1]`), and folding of heading sections in the formatted view. The Format menu and toolbar work in raw mode too, where they insert the Markdown syntax instead, and File > Open Recent lists the last fifteen files. The library search also looks inside every sheet's text and shows the matching line, HTML, PDF, Word and RTF exports embed the images stored beside a document so the file stands alone, files keep their byte-order mark and Windows or classic Mac line endings when saved, and Settings > Files can make Markwright the default app for Markdown files. A companion **iPad app** (document-based, opens Markdown from Files and iCloud Drive) shares the same Markdown core: a syntax-highlighted editor with a formatting toolbar, a live rendered preview beside it, the dashboard, typewriter scrolling, the theme and font settings, and HTML/PDF/RTF export with printing. It was ***100% vibe coded*** using Xcode 26.4.1 and Claude Agent (Opus 4.6, later Fable 5.1) as the AI coding assistant.


The `MarkwrightTests` target holds the unit tests (Swift Testing; Product > Test in the Markwright scheme). It compiles the app's sources directly and runs outside the app, so it never touches an installed copy's documents or settings. Tests marked `withKnownIssue` describe real bugs that haven't been fixed yet.
