# Marky Mark

This application is a single-pane Markdown editor with two faces: a **rendered** view that you edit directly (with a formatting toolbar, keyboard shortcuts, editable tables, task checkboxes and inline images) and a **raw** view where you type the Markdown syntax yourself. The two stay in sync, your last-used mode is remembered, documents auto-save as you type, every document is a tab so several can be open at once, a version history (File > Revert To) lets you step back past auto-saves, and the app reopens whatever you were working on (including unsaved untitled drafts). Inspired by Ulysses, it also has a library sidebar (a folder of sheets and groups with search, keyword filters and Quick Open), a dashboard (statistics, reading time, writing goals with deadlines, outline navigator, keywords, attachments), typewriter scrolling, focus mode, composition mode, editor themes and fonts, comments and metadata blocks, find and replace, grammar checking, splitting a sheet at the cursor, and export to HTML, PDF, Word and RTF with a styled preview and printing. A companion **iPad app** (document-based, opens Markdown from Files and iCloud Drive) shares the same Markdown core: a syntax-highlighted editor with a formatting toolbar, a live rendered preview beside it, the dashboard, typewriter scrolling, the theme and font settings, and HTML/PDF/RTF export with printing. It was ***100% vibe coded*** using Xcode 26.4.1 and Claude Agent (Opus 4.6, later Fable 5.1) as the AI coding assistant.
